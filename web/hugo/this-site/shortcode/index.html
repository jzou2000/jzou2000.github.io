Shortcode

img-list

List of images, inner content is a yaml that defines list of images.

- img: path-to-image
  href: url onclick, optional
  title: optional
  text: optional additional text

class structure:

  • van-img-list van-img-list-${size}
    • van-list-item van-list-item-${size}
      • van-list-head van-list-head-${size}
        • img.van-list-img
      • van-list-desc
        • van-list-title
        • van-list-text

Parameters:

  • size: width of image
    • micro: 80px
    • tiny: 160px
    • small: 320px
    • medium: 64px
    • large: 640px
  • circle: circle-mask, false
  • shadow: false
  • blank: open link (if href is defined) in new window/tab

yt-list

List of YouTube embeds, inner content is a yaml that defines list of YouTube tags.

- yt: "youtube id, i.e. https://www.youtube.com/embed/${yt}"
  title: optional
  text: optional additional text

class structure:

  • van-img-list van-img-list-${size}
    • van-list-item van-list-item-${size}
      • van-list-head van-list-head-${size}
        • iframe.van-list-yt
      • van-list-desc
        • van-list-title
        • van-list-text

Parameters:

class=“van-img-grid van-img-grid-${size}”

  • size: width of youtube video
    • tiny: 120px
    • small: 240px
    • medium: 320px
    • large: 640px

van-img

Put image in tag div with class van-img van-img-${size}

  • src: image file name
  • size: size of image
    • tiny: 160px
    • small: 320px
    • medium: 640px
    • large: 800px
    • full: 80%-98%
