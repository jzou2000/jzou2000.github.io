compare

  • unload models and clean caches for each run
  • enable sage-attention, improvement is not so obvious (yesterday without sage-attention, total 107s, 2nd run 102s)
  • in different downloaded vae (e.g. kijai’s version LTX23_audio_vae_bf16), the log always shows “[INFO] VAE load device: cuda:0, offload device: cpu, dtype: torch.float32”
  • 2nd run: gguf LTXAV model is slowest, however it uses least vram (7878.66 MB usable, 7851.57 MB loaded, 5951.90 MB offloaded, 27.09 MB buffer reserved, lowvram patches: 0)
  • 3rd/4th: LTXAV is staged (what does it mean? load in main memory?), up to 2x sampling speed, but might not be so aggressive (3rd: 3.8s/it, 4th: 5.8s/it)
  • gemma-3-12b-it-Q4_K_M generates a long list warning, but gemma_3_12B_it_fp8_scaled not
  • tried ltx-2.3_text_projection_fp8, the output doesn’t follow prompts, sometimes it goes completely wild.
  • should I try gemma-4-12b (is it compatible) or gemma-3-12b-fp4 (any good) ?
