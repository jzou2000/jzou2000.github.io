sshfs

If you want the remote folder mounted directly into your local filesystem path—allowing local applications, scripts, and GUI file managers to read and write seamlessly—sshfs is the exact SSH equivalent to NFS.

Install SSHFS

# Arch / CachyOS
sudo pacman -S sshfs

# Ubuntu / Debian
sudo apt install sshfs

Create a Mount Point & Mount

# Create a local folder
mkdir -p ~/mnt/kiwi

# Mount remote kiwi home directory (or any path)
sshfs kiwi:/home/username ~/mnt/kiwi -o idmap=user,econnect,ServerAliveInterval=15,ServerAliveCountMax=3,cache=yes

Key Mount Options Breakdown

  • idmap=user: Map your local user to the remote user for full access

  • reconnect: Automatically reconnects if the network drops momentarily.

  • ServerAliveInterval=15: Sends keep-alive packets every 15 seconds to prevent idle disconnects.

  • cache=yes: Caches directory listings locally for smoother browsing in GUI file managers.

Alternative: Explicit UID/GID Mapping

If idmap=user doesn’t resolve the access issue (or if you are mounting as root/another user), you can explicitly force SSHFS to assign file ownership to your local UID and GID:

  1. Find your local UID and GID:

    id

    (Usually outputs uid=1000(yourusername) gid=1000(yourusername)).

  2. Mount using uid and gid overrides:

    sshfs kiwi:/home/username ~/mnt/kiwi -o uid=1000,gid=1000,reconnect,ServerAliveInterval=15

Note on Remote Permissions: If you still get a “Permission denied” error when trying to write/create a file, double-check that the user on kiwi actually has write permissions on those remote files/directories (chmod u+w or correct remote ownership). SSHFS cannot elevate permissions beyond what your SSH user is allowed to do on kiwi.

Unmount When Finished

To safely detach the mount:

fusermount -u ~/mnt/kiwi

Scenario Breakdown

Event What happens to SSHFS? Reconnects Automatically?
1. TP (Local) Sleeps & Wakes Network breaks temporarily while suspended. When waking, SSHFS detects the lost socket and opens a new SSH tunnel in the background. Yes (thanks to -o reconnect)
2. Kiwi (Remote) Sleeps or Reboots Remote SSH daemon closes. SSHFS retries connecting until kiwi comes back online. Yes (as soon as kiwi boots/wakes)
3. TP (Local) Reboots The local FUSE mount process is terminated during shutdown. No (mount vanishes after reboot unless added to /etc/fstab)
