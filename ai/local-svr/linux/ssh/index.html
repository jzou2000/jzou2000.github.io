Is there a way to give a shortcut name for ssh connection target, for example kiwi instead of aiuser@kiwi.local everytime?

Create ~/.ssh if not yet, then edit file ~/.ssh/config, let it contains

Host kiwi
    HostName kiwi.local
    User aiuser

Tighten permission for security

chmod 700 ~/.ssh
chmod 600 ~/.ssh/config

You can use ssh as simple as

ssh kiwk
